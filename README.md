PROJECT OVERVIEW

Sweet Bakery is a multi-page website for a fictional local bakery that sells everyday bread and pastries and takes custom cake orders. It was built in three parts: HTML structure (Part 1), CSS styling (Part 2), and JavaScript functionality with SEO (Part 3).

Target audience: local, everyday customers who buy bread and pastries, and customers placing custom cake orders for special occasions.


PAGES

- index.html - Home page with a welcome section and today's favourites
- menu.html - Full menu with category filter buttons
- about.html - The story behind the bakery
- contact.html - Opening hours, embedded Google Map, and an enquiry form with validation


FOLDER STRUCTURE

- css/style.css - all styling
- js/script.js - all JavaScript
- images/ - image assets used on the site


PART 3 FEATURES

JavaScript
- Scroll animation: sections fade in as they scroll into view. This is switched off automatically for users who prefer reduced motion.
- Menu filter: buttons show or hide menu categories.
- Contact form validation: checks the name, email format, optional phone number format, enquiry type and message length. Errors appear next to each field, and a character counter shows the message length.
- Custom cake date field: only appears when "Custom cake order" is selected, and requires at least 2 days notice.
- The footer year updates automatically.

SEO
- Unique page title and meta description on every page
- Meta keywords, robots tag and Open Graph tags
- Descriptive alt text on every image
- Semantic HTML (header, nav, main, section, footer)
- Schema.org Bakery structured data (JSON-LD) on the home page

External service
- Google Maps is embedded on the contact page.

Accessibility
- Skip-to-content link, visible focus outlines, aria-current on the active page, labelled form fields, and error messages announced with role="alert"


DESIGN NOTES

Colour scheme: warm browns and cream tones to suit a bakery, with a serif typeface for a traditional, welcoming feel.

Responsive design: a media query for screens under 600px stacks the navigation and resizes the header and map for mobile devices.
